# Blog topic backlog

The daily writer takes the **first unchecked topic**, writes it following `content/WRITING.md`, then ticks it
with the post's path and date, e.g. `- [x] How many flashcards… → /blog/how-many-flashcards-a-day/ (2026-11-15)`.

When fewer than 10 topics are left unchecked, it adds 15 new ones at the end: real questions learners
search for, in the same groups, never repeating a topic that already has a post.

Format: `- [ ] Working title — search phrases`
